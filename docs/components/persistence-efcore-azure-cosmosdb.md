# Squirrel.Persistence.EfCore.AzureCosmosDB

Package area for Azure Cosmos DB persistence integrations.

## Install

```bash
dotnet add package Squirrel.Persistence.EfCore.AzureCosmosDB
```

Use this adapter when a service stores its EF Core-backed data in Azure Cosmos DB. Keep Cosmos connection details in configuration or managed identity settings and add the package alongside the abstractions and core packages used by the service.

Check the package release notes for the currently supported registration surface before production adoption.
